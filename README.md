Python Ultimate Clock App
ttkbootstrap を活用した、モダンで多機能なデスクトップ時計アプリケーションです。
アラーム、ストップウォッチ、そして視覚的な円形タイマーを一つの洗練されたインターフェースに統合しました。

🚀 特徴
洗練されたモダンUI: ttkbootstrap (Darklyテーマ) を採用。標準のTkinterでは難しい、スタイリッシュなダークモードを実現。

3-in-1 ユーティリティ:

ALARM: 複数のアラームを登録・管理可能。

STOPWATCH: 1/100秒単位で計測可能な高精度ストップウォッチ。

TIMER: 直感的な円形プログレスメーターを備えたカウントダウンタイマー。

インタラクティブ・フィードバック: Meter ウィジェットにより、タイマーの経過をアニメーションで視覚的に把握できます。

スマート通知: Windows標準の winsound によるビープ音と、メッセージボックスによる通知機能を搭載。

🛠 技術スタック
GUI: ttkbootstrap (Tkinterの上位互換ライブラリ)

Audio: pygame.mixer / winsound (Windows)

Logic: time モジュールによる高精度な時刻計算、after() メソッドによる非同期更新。

🚀 クイックスタート
1. 依存ライブラリのインストール
以下のコマンドを実行して、必要なパッケージをインストールしてください。

Bash
pip install ttkbootstrap pygame
2. 実行
Bash
python main.py
🕹 使い方
アラーム: 時・分を選択して「+」ボタンをクリック。時刻になると通知されます。

ストップウォッチ:

START ボタンで計測開始。

STOP で一時停止。

RESET でリセットします。

タイマー: 秒数を入力して START TIMER をクリック。円形メーターがリアルタイムで減少します。

📂 ファイル構成
main.py: アプリケーションのメインコード。

(オプション) Clock-Alarm05-1(Mid).mp3: アラーム音として使用する場合に配置。
